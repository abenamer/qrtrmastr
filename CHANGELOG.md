# Changelog

## 0.1.0 — unreleased

- Process: a Dependabot pull request is never merged as it stands; its bump is redone on a reviewed branch by the commit protocol, and Dependabot's version updates arrive grouped per ecosystem once a month. `actions/checkout` moves to 7.0.1 and `gitleaks/gitleaks-action` to 3.0.0 (Node 24 runtime). [ADR 0002](docs/decisions/0002-pull-requests-and-the-security-review-on-every-commit.md).
- Process: the security review on every commit is literal, including documentation-only, canary and hook changes; recorded in `CLAUDE.md` and [ADR 0002](docs/decisions/0002-pull-requests-and-the-security-review-on-every-commit.md).
- Run as a container: `Dockerfile` and a `qm` service in `compose.yaml` under a profile, so `docker compose up -d` starts the database and `docker compose run --rm qm <command>` runs the tool with your exports at `/data`, your configuration at `/config` and the local fixtures at `/fixtures`. Nothing is installed on the host.
- Import and recommend (milestone 1): `qm import --mbox <path>` reads a Google Takeout export of the FreshDirect label, redacts each message before storing it once, parses every receipt in the 2026 layout into an order with its lines, keeps rows it cannot classify as anomalies, resolves products through aliases, and writes each attempt in one guarded transaction; `qm due` lists what the usual gap between purchases says you are about to run out of, with `--simple` for the frequency rule and `--json`; `qm fixture add` writes a stored redacted receipt as a local fixture. Configuration in `~/.config/qrtrmastr/config.toml`: redaction terms, thresholds, senders. [ADR 0003](docs/decisions/0003-one-time-takeout-import-with-the-gmail-api-deferred.md), [ADR 0004](docs/decisions/0004-redaction-before-storage.md), [ADR 0005](docs/decisions/0005-product-identity-through-aliases.md), [ADR 0006](docs/decisions/0006-recommendation-by-usual-gap-with-a-simple-rule-beside-it.md).
- Scaffold (milestone 0): the Cargo package `qrtrmastr` with the binary `qm`, the REAS layout (`src/domain`, `src/application`, `src/adapters`, `src/main.rs`), identifier newtypes, exact money and quantities, the stored labels and the `ParseState` lifecycle, the `SchemaStore` port and the `Migrate` use case, `PostgresStore`, and `qm migrate`. Migrations `0001_raw_mail.sql` and `0002_grocery.sql` create the MVP schema. CI with seven required jobs (format, check, clippy, migrations, checked queries, tests; audit; deny; gitleaks; privacy canary; docs; dependency review), Dependabot, the Compose file with a named volume, and the Claude Code setup. [ADR 0001](docs/decisions/0001-ports-and-adapters-for-a-private-tool.md) and [ADR 0002](docs/decisions/0002-pull-requests-and-the-security-review-on-every-commit.md).
