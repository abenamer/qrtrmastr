# Bundle update log

## 2026-11-13
* **New**: The project scaffold, milestone 0 of the MVP plan. A Cargo package `qrtrmastr` with the binary `qm` and the REAS layout: `src/domain` (identifier newtypes, exact money and quantities, the stored labels and the `ParseState` lifecycle), `src/application` (the `SchemaStore` port and the `Migrate` use case), `src/adapters` (`PostgresStore`, the settings reader, the clap command line), `src/main.rs` as the composition root. Migrations `0001_raw_mail.sql` and `0002_grocery.sql` create the tables of the MVP schema and the `purchases` view. `tests/database.rs` runs against a real PostgreSQL. [ADR 0001](/decisions/0001-ports-and-adapters-for-a-private-tool.md) records the architecture selection; [ADR 0002](/decisions/0002-pull-requests-and-the-security-review-on-every-commit.md) records the pull-request flow and the security review on every commit: the seven CI jobs (`.github/workflows/ci.yml`, actions pinned by commit), `deny.toml`, `.gitleaks.toml`, `.cargo/audit.toml` (RUSTSEC-2026-0459 ignored with the reason), the privacy canary `scripts/pii_canary.sh`, and the Claude Code setup (`.claude/`: permissions, three hooks, path-scoped rules; `CLAUDE.md`, `AGENTS.md`). The REAS standard 1.4.0-draft is vendored at `standards/reas/` from the nbastats copy. Documents: [Application overview](/concepts/application.md), [Privacy](/concepts/privacy.md), [Database schema](/reference/schema.md), [Command line](/reference/cli.md), [Configuration](/reference/configuration.md), [Develop](/runbooks/develop.md), the [terminology](/terminology.md), the [self-audit](/self-audit.md) and the [STE review](/ste-review.md). Checks that ran on the staged scaffold on 2026-11-13: `cargo fmt --all -- --check`, `cargo check --all-targets`, `cargo clippy --all-targets -- -D warnings` (no warnings), `cargo test --lib` (16 passed), `cargo test --test database` (3 passed, fresh databases on a user-owned PostgreSQL 15 at port 5433), `qm migrate` twice (2 applied, then 0 applied and 2 already applied), `cargo sqlx prepare --check`, `cargo deny check`, `cargo audit` (RUSTSEC-2026-0459 ignored, reason in `.cargo/audit.toml`), `python3 scripts/check_docs.py`, the docs checker tests (6 passed), `scripts/pii_canary.sh` (one false positive on a test's reserved-domain Message-ID, fixed by excluding RFC 2606 domains). Security review (`/security-review`, one review agent and three filter agents over the staged tree): no finding at or above the reporting threshold. Three hardening notes, all applied before the commit: the privacy canary passed file names through `xargs` and swallowed grep's exit status, so a file name with a space was never scanned and the run still reported PASS (fixed: file names as arguments, `pipefail`, any grep status other than match or no-match fails the run); `backups/` was bind-mounted into the database container but not ignored by git (fixed: `/backups/*` ignored, and the canary fails when anything but `.gitkeep` is tracked there); the guard hook's block lists were narrow and the documents called it a control (fixed: `docker volume rm`, wrapped and escaped `git`, refspecs that land on `main`, and any command that names an export file outside the import tooling are refused; [Privacy](/concepts/privacy.md), `CLAUDE.md`, [Develop](/runbooks/develop.md) and ADR 0002 now call the hook a best-effort backstop and name the Read denies, the permission prompts and branch protection as the controls).
