# Bundle update log

## 2026-11-13
* **New**: The `qm` command runs as a container beside its database. `Dockerfile` builds the binary in a Rust stage and copies it into a slim Debian image that runs as an unprivileged user; `.dockerignore` sends only the build inputs to the context. `compose.yaml` gains the `qm` service under a profile, so `docker compose up -d` starts the database alone and `docker compose run --rm qm <command>` runs one command: the exports directory (`QM_DATA_DIR`) is `/data` read-only, the configuration directory (`QM_CONFIG_DIR`) is `/config` read-only, `tests/fixtures/local` is `/fixtures`, and the container has a read-only root, no capabilities and no new privileges. Nothing of the project is installed on the host, at the maintainer's request. * **New**: Milestone 1, import and print what is due. `qm import --mbox <path>` reads a Takeout export through the `MboxFile` adapter, prepares each message with the `FreshDirectMail` reader (MIME, sender check, kind from the subject, DKIM pass, redaction in four passes with an assertion), stores it once by `Message-ID` or source hash, then parses every waiting receipt with the `fd_receipt_2026` parser through the registry, reconciles it, resolves each line to an alias and writes order, lines, anomalies, the attempt and the guarded state transition in one transaction. `qm due` ranks items by the gap rule, or by the simple rule with `--simple`, with `--json`. `qm fixture add <key>` writes a stored redacted body under the gitignored local fixtures directory. The configuration file `config.toml` holds the redaction terms, the thresholds and the senders. Domain: `receipt.rs` (reconciliation), `identity.rs` (normalization), `recommend.rs` (both rules); application: `import.rs`, `parse.rs`, `recommend.rs`, `fixture.rs`; adapters: `mail/`, `receipts/`, `fixtures.rs`, the Postgres implementations of the new ports. A synthetic receipt fixture in the 2026 layout, with fake personal data in reserved shapes, drives the parser snapshot and the redaction tests; the canary skips the synthetic inputs and scans what the redactor produces.
